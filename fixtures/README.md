# Fixtures (real API responses)

**These files are real responses of the backend API** (`backend/clearinghouse/api.py`),
regenerated by `backend/scripts/regenerate_fixtures.py` on 2026-10-18 (in process, via FastAPI's
TestClient). They are no longer hand-written mock data. The frontend's fixture mode serves
them (`frontend/scripts/sync-fixtures.mjs` copies them into `frontend/src/fixtures/`).

**Example scenario rule** (fixed before any result was seen, never adjusted after):
`clear_request.json` has exactly one company per preset from `GET /api/presets` (ids
`b1..b5`, names from the presets) on `meta.default_day` (2024-03-29, the first pre-registered demo
day) with the default background (10% of forecast peak), carbon price ($50/t) and pool
($100,000); the defaults are illustrative. `evaluate_request.json` uses the same bids with a
rule-based hand schedule: each bid spread flat over its window (energy / window hours MW per
hour).

**Scroll-section scenario (not pre-registered):** `herding_scroll_*` back the story page's
scroll-scrubbed animation (`frontend/src/components/HerdingScroll.tsx`), which calls the live
API and falls back to this recording. Unlike the example scenario, it was **chosen after looking
at results**: the four presets that appear in the animation (`b1..b4`) were cleared on each demo
day at 0/5/10/20/30% background, and 2024-08-20 at 30% was picked because it shows a herding gap,
coordination gains and a gain over default together. On other days and backgrounds the results
are mixed; the page says so. Not written by this script: re-record it by posting
`herding_scroll_request.json` to the live API's `/api/clear`.

Hour convention: slot `h` (0-23) covers `[h:00, h+1:00)` fixed CST; `earliest_hour` (0-23) is
the inclusive start and `deadline_hour` (1-24) the exclusive end. The coordinator trace uses the
engine's 1% blocks, aggregated to at most 200 steps (several entries may share a step).
`forecast.latency_ms` is the measured wall time of that request's forecast call, so it changes
on every regeneration.

Example-scenario outcome at generation time: total CO2 default 96,343 t, independent_average 96,343 t, independent_marginal 96,343 t, coordinated 96,343 t; fallback_fired=false; total avoided vs independent_marginal 0.0 t; payouts $0 of $100,000.
