# Synthetic documents for bid extraction

Ten fictional documents (bills, a chiller sub-meter statement, a Scope 2 inventory excerpt, a
charging plan, a job-scheduler screen and hourly load charts), each encoding one flexibility
bid. Used by the upload-to-prefill feature (demo works offline) and by
`backend/scripts/eval_extract.py` (`make eval-extract`). All names are made up and every
document carries a "SAMPLE — synthetic test document" footer.

- `src/*.html`: sources, generated by `backend/scripts/make_extract_fixtures.py`.
- `*.png`: renders of `#doc` in each HTML (gstack headless browser; any browser screenshot
  of the `#doc` element at 900 px wide works).
- `ground_truth.json`: the answer key per image (`earliest_hour`, `deadline_hour`,
  `energy_mwh` per day, `max_mw`) and how it is derived.

Regenerate: `cd backend && uv run python scripts/make_extract_fixtures.py`, then re-render the
PNGs. The `bill_01` key was corrected to 7.332 MWh (94% of the energy is charging) after the
model's first extraction pointed out the original key ignored that share.
